# Маршрутизация, TUN и Split Tunneling

## Режимы трафика
1. **Системный прокси** — настраивает WinINet системный прокси Windows (`HKCU\...\Internet Settings`). Не требует прав администратора, подходит для браузеров и большинства приложений.
2. **TUN (Wintun `0.14.1`)** — перехватывает весь IP-трафик системы на уровне виртуального сетевого адаптера. Требует запуска с правами администратора для поднятия маршрутов и DNS-перехвата.
   - В `v0.5.0` DNS-запросы (`udp/tcp :53`) явно направляются в `dns-out`.
   - При выключенном IPv6 добавляется блокирующий маршрут `::/0`, предотвращающий утечку IPv6 мимо туннеля.

## Kill Switch
- **Fail-closed защита**:
  - В режиме системного прокси блокирует трафик через локальный прокси-контур.
  - В режиме TUN настраивает правила Windows Firewall для предотвращения утечки трафика в обход туннеля. Если у процесса нет прав администратора для создания правил firewall в режиме TUN, приложение явно предупреждает пользователя вместо молчаливого отката.

## Split Tunneling и правила
- Доступны режимы маршрутизации по доменам, IP/CIDR-подсетям и процессам Windows.
- Пользовательские правила применяются совместно со встроенными пресетами («Только обход», «РФ напрямую», «Весь трафик через VPN») без потери порядка приоритета.
