# Установка и обновление AURA VPN

## Системные требования
- **ОС**: Windows 10 / Windows 11 (x86_64).
- **Среда выполнения**: Microsoft Edge WebView2 Runtime (установлена по умолчанию в Windows 11 и большинстве сборок Windows 10).
- **Права администратора**: не требуются для обычной работы в режиме системного прокси; требуются для режима **TUN (Wintun)** и системного firewall **Kill Switch** в TUN-режиме.

## Установка и тихое обновление поверх v0.4.0
1. Запустите установщик `AURA VPN_0.5.0_x64-setup.exe`.
2. Режим установки — `currentUser` (`%LOCALAPPDATA%\AURA VPN\`), без конфликтов пользовательского профиля.
3. Для автоматического или тихого обновления с версии `0.4.0` закройте `aura-vpn.exe` и выполните:
   ```powershell
   & ".\AURA VPN_0.5.0_x64-setup.exe" /S
   ```

## Сохранность данных при обновлении
- Все серверы, подписки, настройки и пользовательские правила маршрутизации располагаются в `%APPDATA%\app.auravpn.desktop\` и **не затрагиваются** установщиком.
- При первом запуске `v0.5.0` существующие незашифрованные конфиги автоматически мигрируют в формат с защитой **Windows DPAPI** (`CryptProtectData`), а пользователям с уже добавленными профилями экран онбординга не навязывается.
